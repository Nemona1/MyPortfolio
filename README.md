## About The Project

<div align="center">
  <img src="public/apple-touch-icon.png" alt="Portfolio Screenshot" width="600" />
</div>

This is my personal portfolio website showcasing my skills, projects, and experience as a Full-Stack Developer. It features a modern, responsive design with smooth animations and an intuitive user experience.

### Key Highlights

- 🎨 **Modern UI/UX** - Clean, professional design with gradient accents and smooth animations
- 📱 **Fully Responsive** - Optimized for all devices from mobile to desktop
- 🚀 **Performance Optimized** - Fast loading with code splitting and lazy loading
- ♿ **Accessible** - Built with accessibility best practices
- 🔍 **SEO Friendly** - Meta tags and semantic HTML for better search visibility

### 🏠 Home Section
- Animated typing effect for skills
- Profile image with gradient border

- Professional experience timeline

- Social media integration

- Mobile-first approach
- Collapsible navigation menu
- Optimized images and content
